Um pequeno aplicativo desenvolvido para organizar, transferir e reproduzir arquivos multimídia durante uma comemoração privada de aniversário.

Objetivo:
O projeto foi criado como parte de uma surpresa coletiva de aniversário. Cada participante poderá contribuir com arquivos, como músicas, desenhos, vídeos e outras criações, que serão apresentados ao aniversariante em uma ocasião especial.

Funcionalidades:
Envio de arquivos entre os participantes.
Organização dos arquivos recebidos.
Reprodução dos conteúdos na ocasião programada.
Interface simples para facilitar a utilização.
 
Aviso de uso responsável:
Este software foi desenvolvido exclusivamente para fins recreativos e para uma brincadeira privada, com o objetivo de proporcionar uma surpresa de aniversário.
Não foi desenvolvido para causar danos, acessar dispositivos sem autorização, executar arquivos sem consentimento ou comprometer a privacidade e a segurança de terceiros.
Sua utilização deve ocorrer somente em dispositivos próprios ou com autorização explícita de seus responsáveis.

bibliotecas:
OS, FLASK, JSON
